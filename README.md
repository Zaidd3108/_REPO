# Proyecto DataSalud Perú: Análisis CRED e INEN

Repositorio oficial del grupo para el desarrollo del proyecto de ingeniería de datos y Business Intelligence enfocado en el análisis de atenciones de salud en el Perú.

## 📁 Estructura del Repositorio
- **Spark/**: Contiene el pipeline ETL desarrollado en PySpark y la documentación del procesamiento.
- **sql/**: Notas técnicas y referencias de la base de datos y esquemas del Data Warehouse.
- **powerbi/**: Contiene el reporte interactivo final (`DataSaludPeru_Reporte.pbix`).

## 🛠️ Tecnologías Utilizadas
- **Apache Spark / PySpark**: Procesamiento de datos y pipeline ETL.
- **SQL Server**: Gestión del Data Warehouse y modelo dimensional.
- **Power BI**: Modelado en estrella y diseño del panel interactivo (Dashboard).

## 🚀 Instrucciones de Ejecución
1. **Pipeline ETL (Spark):** Abrir y ejecutar el notebook `PySpark.ipynb` en la carpeta `Spark/`.
2. **Base de Datos (SQL Server):** Restaurar el archivo de respaldo (`.bak`) en SQL Server para habilitar el Data Warehouse.
3. **Reporte (Power BI):** Abrir el archivo `DataSaludPeru_Reporte.pbix` en la carpeta `powerbi/` para explorar los indicadores y filtros interactivos.
